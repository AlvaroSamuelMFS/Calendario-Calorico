# Calendario de Comidas

Aplicación de escritorio en Python para planificar comidas semanales
según tu objetivo (tonificar o adelgazar), con cálculo de calorías y macros

## Instalación
1. Clona el repositorio
2. `pip install -r requirements.txt`
3. Consigue una API key en https://fdc.nal.usda.gov/api-key-signup
4. Crea un archivo `.env` con `USDA_API_KEY=tu_key`
5. Ejecuta `python main.py`

## Tecnologías
Python, CustomTkinter, SQLite, requests, bcrypt
